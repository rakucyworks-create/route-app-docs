# 利用規約

この利用規約(以下「本規約」といいます)は、RakucyWorks(以下「当社」
といいます)が提供するアプリケーション「スタールート」(以下「本サービス」
といいます)の利用条件を定めるものです。本サービスをご利用になる方
(以下「ユーザー」といいます)には、本規約に従って本サービスをご利用
いただきます。

## 第1条(適用)

1. 本規約は、ユーザーと当社との間の本サービスの利用に関わる一切の
   関係に適用されるものとします。
2. 当社が本サービス上で掲載する本サービス利用に関するルール等は、
   本規約の一部を構成するものとします。
3. 本サービスは、日本国内でのご利用を想定しています。

## 第2条(利用登録)

1. 本サービスの一部の機能は、登録の有無にかかわらずご利用いただけます。
2. 本サービスのルート作成機能は、利用登録なしでもお試しいただけます。
   有料プランへのご加入も、利用登録なしで行うことができます。
   ただし、利用登録を行わないまま、機種変更やアプリの再インストールを
   行った場合、保存したプラン・お気に入りスポット等のデータは、
   復元できなくなります。有料プランをご契約中の場合、ご契約
   (お支払い)そのものは、ストアの「購入の復元」機能により引き継げる
   場合がありますが、保存データについては、この限りではありません。
   大切なデータを保持されたい場合は、あらかじめ、メールアドレス
   及びパスワードによる利用登録を行うことをおすすめします。
3. 当社は、利用登録の申請者に以下の事由があると判断した場合、
   利用登録の申請を承認しないことがあり、その理由については
   一切の開示義務を負わないものとします。
   - 虚偽の事項を届け出た場合
   - 本規約に違反したことがある者からの申請である場合
   - その他、当社が利用登録を相当でないと判断した場合
4. メールアドレスの登録手続きを開始した後、24時間以内に、確認メールの
   リンクによる確認を完了されない場合、当該登録手続きは無効となり、
   当該登録手続きに関する情報(それまでに保存されたプラン、お気に
   入りスポット等のデータを含みます)は削除されます。再度ご利用に
   なる場合は、あらためて登録手続きを行ってください。
5. 未成年のユーザーが、法定代理人の同意を得ずに、有料プランへの
   加入等の法律行為を行った場合、当該ユーザーまたはその法定代理人は、
   これを取り消すことができるものとします。

## 第3条(無料お試しについて)

1. 本サービスでは、初めてご利用いただくお客様に限り、所定の回数まで
   無料でルート作成機能をお試しいただけます(以下「無料お試し」と
   いいます)。
2. 無料でお試しいただける回数は、当社の判断により、予告なく
   変更される場合があります。ただし、すでにお試しいただける
   回数が確定したお客様について、当社都合により事後的に回数を
   減らすことはありません。
3. 無料お試しは、お一人様一回限りとし、複数回の付与は行いません。
4. 無料お試しの回数には、金銭的価値はなく、換金・譲渡はできません。
5. アカウントを削除された場合、保存したプラン・お気に入りスポット等の
   データは削除されますが、無料お試しの利用状況に関する記録は、
   個人を特定できない、技術的な識別情報の範囲で、不正利用防止の
   目的により、削除操作から1年間保持されます。この間、同一の端末・
   アプリからは、無料お試しが再付与されないことがあります。

## 第4条(お試しオファーについて)

1. 当社は、有料プランへの、初めてのご契約に限り、期間限定の
   割引価格及び/又は増量されたルート作成回数を提供する場合が
   あります(以下「お試しオファー」といいます)。無料お試し
   (第3条)とは、別の制度です。
2. お試しオファーの提供の有無、内容(割引価格・回数・提供期間)は、
   当社の判断により、予告なく変更・終了することがあります。
3. お試しオファーの対象者の判定(過去のご契約の有無等)は、
   App Store(Apple Inc.)もしくはGoogle Play(Google LLC)の
   定める基準、または、当社が定める基準に従って行われます。
4. お試しオファーの条件でご契約いただいたお客様については、
   当該オファーで定められた期間中、契約時点の条件が継続して
   適用されます。オファー期間の終了後は、その時点における通常の
   利用料金及びルート作成回数(第5条の変更が反映されている場合は、
   その内容)が適用されます。

## 第5条(料金及び支払方法)

1. ユーザーは、本サービスの有料プラン(以下「本プラン」といいます)に
   加入することで、無料お試しの回数を超えて、ルート作成機能を
   ご利用いただけます。
2. 本プランの種類及び料金は、本サービス内の表示するところによります。
3. 本プランの購入及び決済は、App Store(Apple Inc.)、
   またはGoogle Play(Google LLC)を通じて行われ、各社の定める
   利用規約及び決済条件が適用されます。
4. 本プランは自動更新されるサブスクリプション形式です。ユーザーは、
   ご利用のストア(App StoreまたはGoogle Play)の設定画面から、
   いつでも解約手続きを行うことができます。
5. 本プランの解約は、次回更新日の前までに手続きを行わない限り、
   当該更新日をもって自動的に更新されます。解約後も、既に
   お支払いいただいた期間については、本プランをご利用いただけます。
   なお、解約手続き後は、第6条に定める料金・ルート作成回数の
   変更は適用されません。
6. 本プランの利用に伴うルート作成回数は、契約期間ごとにリセット
   され、未使用分の翌期間への繰り越しは行いません。

## 第6条(料金・利用条件の変更)

1. 当社は、経済情勢の変化、本サービスの提供コストの変動その他の
   合理的な理由により、本プランの利用料金及びルート作成回数等の
   利用条件を変更することがあります。
2. 前項のうち、利用料金の変更については、App Store及び
   Google Playの定める方法により、既存の契約者に通知されます
   (通知方法・時期は、各ストアの定めによります)。当社は、
   本サービス内にも、変更内容を、参考情報として表示する場合が
   あります。
3. 第1項のうち、ルート作成回数の変更については、当社は、
   変更の内容及び適用開始日を、適用開始日の30日前までに、
   アプリ内の通知により周知します。既存の契約者については、
   告知した適用開始日以降に到来する、最初の更新のタイミングから、
   新しいルート作成回数が適用されるものとします。
4. 前項の変更は、本サービス内の「現在のプラン」画面等において、
   契約状況に応じた形で表示されますが、正確な適用時期は、
   ご契約の状況(契約中のプラン、更新タイミング、解約手続きの
   有無等)により異なります。ご契約中のプランに関する正確な
   条件は、ご利用のストアの購入・契約確認画面にてご確認ください。
5. 第4条に定めるお試しオファーの条件で契約されたお客様については、
   本条の定めにかかわらず、第4条の定めが優先して適用されます。
