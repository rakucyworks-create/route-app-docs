# プライバシーポリシー

RakucyWorks(以下「当社」といいます)は、当社が提供するアプリケーション
「スタールート」(以下「本サービス」といいます)における、ユーザーの
個人情報の取扱いについて、以下のとおりプライバシーポリシー(以下
「本ポリシー」といいます)を定めます。

## 第1条(事業者情報)

事業者名:RakucyWorks
お問い合わせ先:rakucyworks@gmail.com

## 第2条(取得する情報)

当社は、本サービスの提供にあたり、以下の情報を取得します。

1. **アカウント情報**:メールアドレス(パスワードは、Firebase
   Authentication(Google LLC)により安全に管理されており、当社が
   直接、取得・保存することはありません)
2. **位置情報**:出発地・目的地の位置情報、現在地情報
   (現在地機能をご利用いただいた場合)
3. **利用履歴**:作成したルートプラン、登録したお気に入りスポット、
   ルート作成回数の利用状況
4. **課金情報**:ご利用中のプラン、契約状況(お試しオファーの
   利用状況、自動更新の設定状況を含みます。クレジットカード
   番号等の決済情報そのものは、当社では取得せず、App Storeまたは
   Google Playが管理します)
5. **お問い合わせ情報**:お問い合わせいただいた際に、ご利用の
   アプリのバージョン等、対応に必要な範囲の情報
6. **本サービスの改善のための情報**:上記のほか、本サービスの
   改善を目的として、端末情報、アプリの利用状況、エラーログ等の
   情報を取得する場合があります。

## 第3条(利用目的)

当社は、取得した情報を、以下の目的で利用します。

1. 本サービスの提供、維持、保護及び改善のため
2. ルート作成機能における、最適な経路の計算のため
3. 無料お試し、お試しオファー及び有料プランのご利用状況を
   管理するため
4. ユーザーからのお問い合わせに対応するため
5. 本サービスに関する重要なお知らせ(利用規約の変更、料金改定等)を
   通知するため
6. 不正利用の防止、利用規約違反への対応のため
7. 本サービスの利用状況を分析し、改善するため

## 第4条(第三者提供・外部送信)

当社は、本サービスの提供にあたり、以下の外部サービスを利用しており、
これらのサービス提供者に対して、必要な範囲で情報が送信されます。

| サービス | 提供者 | 送信される情報の例 |
|---|---|---|
| Firebase(認証、データベース、サーバー機能) | Google LLC | メールアドレス、位置情報、利用履歴 |
| Google Maps Platform(地図表示、経路計算、住所検索) | Google LLC | 位置情報(出発地・目的地の緯度経度、住所) |
| RevenueCat(サブスクリプション管理) | RevenueCat, Inc. | 契約状況、購読情報 |
| App Store / Google Play(決済) | Apple Inc. / Google LLC | 購入情報(決済情報そのものは、当社には送信されません) |

これらの外部サービスにおける情報の取扱いについては、各社が定める
プライバシーポリシーが適用されます。

当社は、法令に基づく場合を除き、あらかじめユーザーの同意を得ることなく、
上記以外の第三者に個人情報を提供することはありません。

当社が利用する、Firebase(Google LLC)、Google Maps Platform
(Google LLC)、RevenueCat(RevenueCat, Inc.)は、いずれも日本国外に
拠点を置く事業者です。これらのサービスを通じて取得した情報は、
各社のサーバーが所在する日本国外において処理される場合があります。
各社は、それぞれ適切な安全管理措置を講じています。

## 第5条(お試し・料金プランの管理について)

本サービスでは、公平な運用のため、以下のような形で情報を管理して
います。

1. 無料お試しの回数は、初めてアプリを起動した時点の設定内容が、
   端末(アカウント)ごとに記録されます。
2. お試しオファー及び有料プランをご契約いただいた場合、
   契約時点の料金・ルート作成回数等の条件が、契約状況として
   記録されます。
3. お試しオファーの対象者判定は、App StoreまたはGoogle Playの
   基準に従って行われるため、当社は、その判定結果(対象か否か)
   を取得しますが、判定の詳細な基準そのものは管理していません。
4. メールアドレスの登録手続きを開始してから、24時間以内に確認が
   完了しない場合、当該登録手続きに関する情報は、自動的に削除
   されます(詳細は、利用規約の定めによります)。

## 第6条(Cookie等の取扱い)

本サービスは、外部サービス(Google Maps Platform等)の利用に伴い、
Cookieに類する技術が使用される場合があります。これらは、本サービスの
機能提供のために必要な範囲で使用されます。

## 第7条(安全管理措置)

当社は、取得した個人情報の漏えい、滅失またはき損の防止その他の
個人情報の安全管理のために必要かつ適切な措置を講じます。

## 第8条(開示、訂正、削除等の請求)

1. ユーザーは、当社が保有する自己の個人情報について、開示、訂正、
   利用停止、削除を請求することができます。
2. 本サービスの設定画面から、保存したプラン・お気に入りスポット等の
   データを、いつでもご自身で削除いただけます。
3. 削除されたデータは、復元できません。なお、不正利用防止の目的で、
   無料お試しの利用状況に関する、個人を特定しない技術的な記録
   (利用者情報を含まない、識別子及びフラグ情報)は、削除の対象外と
   します。この記録は、削除操作から1年間保持された後、当社の
   定期的な処理により、完全に削除されます。また、有料プランを
   ご契約中の場合、データの削除は、ストア(App StoreまたはGoogle Play)
   側のサブスクリプション契約を自動的に解約するものではありません。
   契約の解約は、別途ストアの設定画面から行っていただく必要が
   あります。
4. アカウントを削除された場合であっても、他のユーザーと共有される
   検索キャッシュ等、個人を特定できない形で保持される技術的な
   情報は、削除の対象に含まれない場合があります。
5. その他の開示等のご請求については、第1条記載のお問い合わせ先まで
   ご連絡ください。

## 第9条(未成年者の利用について)

未成年のユーザーが本サービスを利用する場合、あらかじめ親権者等の
法定代理人の同意を得た上でご利用ください。

## 第10条(本ポリシーの変更)

1. 当社は、法令の改正その他の合理的な理由がある場合には、
   本ポリシーを変更することがあります。
2. 前項の変更のうち、重要な変更については、当社は、本サービス内の
   表示、ウェブサイトへの掲載その他の適切な方法により、これを
   周知します。
3. 変更後のプライバシーポリシーは、前項の周知を行った時点、
   または、本サービス内もしくはウェブサイト上に表示した時点より
   効力を生じるものとします。
